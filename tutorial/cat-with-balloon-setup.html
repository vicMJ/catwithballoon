Cat with Balloon 26.3

New setup for the server. Do this once, about 5 minutes. After that, mods update by themselves every time you press Play.

Don't update your old instance. Make a new one from the file below. Old 26.2 mods left in an old mods folder will crash the game.

Set it up

  1. Download the pack file

    Download cat-with-balloon-26.3.zip 100 KB

    It's tiny on purpose. The mods download when you first launch.

  2. Import it into Fjord Launcher

    Click Add Instance → Import → Browse, pick the zip, then OK. Dragging the zip onto the launcher window works too.

    A new instance called cat with balloon 26.3 appears.

  3. Bring your settings and maps along optional

    Right-click your old instance → Folder. Do the same for the new one. Copy these from the old minecraft folder into the new one:

    • options.txt: keybinds, video and sound settings
    • xaero and XaeroWaypoints: your minimap, world map and waypoints
    • screenshots, and any resource packs you added yourself

    Never copy the mods folder.

  4. Press Play

    An Updating modpack window appears and downloads 44 mods and 12 shaders. The first time takes a minute or two. Later launches only fetch what changed.

    Use the same account you used before.

  5. Join the server

    The server is already in your Multiplayer list as cat with balloon. Pick the Tailscale entry if you're on Tailscale, otherwise the public one.

    Once everything works you can delete the old instance.

From now on

Fine to do

  • Change any settings, keybinds or mod options. Updates never reset them.
  • Pick a different shader in Iris.
  • Add your own resource packs.
  • Change memory: Edit instance → Settings → Java (it's 6 GB by default).

Don't do

  • Add, remove or update mods yourself, including the launcher's "Update" button on the Mods tab.
  • Drop jars into the mods folder.
  • Remove the pre-launch command in the instance settings. That's what keeps you updated.

If something goes wrong

The update window shows an error
Check your internet and press Play again. If it keeps failing, screenshot the window and send it to Jorryn.
"Incompatible mods" or version mismatch when joining
The pack was probably updated while your game was open. Close Minecraft and press Play again. The update runs at launch.
The game crashes on start
Don't delete anything. Send Jorryn the crash report (Edit instance → Minecraft Log, or the crash-reports folder).
The launcher asks which Java to use
Pick Java 25, or let the launcher download it automatically.
